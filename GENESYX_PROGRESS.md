The app count rose by nine with the display-name fix, by two more with the sync-race batch, by
three with the calendar batch, by twelve with the supplement sync and by four with the sign-out
batch, and the domain count by one for the ovulation copy; the UI count rose by four with the
Profile audit, four more with the pH batch and one with the supplement time picker. Each of those
forty was also proven to fail when the behaviour it covers is removed.

**The supplement batch is the clearest evidence yet that the three suites are not interchangeable.**
Everything about the sync was proven by the fast suites — the merge, the tombstones, the migration,
the rejected names, all 30 new tests green in about a second. And the app still crashed the moment
anyone tapped "Review Plan", because moving supplements onto the account meant that screen now needs
something handed to it when the app starts, and it was not being handed it. No unit test could see
that; they build the screen's data themselves. The slow, twelve-minute test that actually taps the
button caught it on the first run, which is exactly what it was written for. It is fixed and re-run
green. **The lesson is the ordering: a green fast suite is not a releasable app, and the slow suite
has to run before anything ships, not after.**

**One test in the calendar batch was not added but rewritten, and that is worth saying plainly.**
The check on "when is my next period due" had the wrong answer written into it — it asserted the
number the code produced rather than the number that is true. So a countdown that was a day short
for every user on every cycle passed its own test suite, month after month, without anything
looking wrong. A test that records what the code does cannot catch the code being wrong. This one
now spells out the arithmetic, and a second test covers the day it went visibly wrong.

The pH batch is also the first time an existing guard caught **us**. A change made in that batch
tripped the automated check that keeps the Home pH card free of health claims. That is the system
working: the change was reverted rather than the check relaxed, and the reasoning on both sides is
recorded under "Found while auditing" rather than settled quietly.

A green suite proves the behaviour under test, not that the app is releasable. Release confidence
also needs the three device- and account-dependent items above.
